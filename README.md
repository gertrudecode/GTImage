# GT Image

이미지 비율 변환과 ICO 변환을 하는 데스크톱 앱입니다. Windows와 macOS를 지원합니다.

## 내려받기

**[최신 버전 받기](https://github.com/gertrudecode/GTImage/releases/latest)**

| 운영체제 | 파일 |
|---|---|
| Windows | `GT-Image-Setup-x.y.z.exe` |
| macOS (Apple Silicon) | `GTImage-x.y.z-arm64.dmg` |

### macOS에서 처음 열 때

코드 서명이 없어서 그냥 두 번 눌러서는 열리지 않습니다.

**시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래로 스크롤하면
**"GT Image이(가) 차단되었습니다"** 옆에 **"그래도 열기"** 버튼이 있습니다.
누르고 확인하면 끝이고, 한 번만 하면 그다음부터는 평소처럼 열립니다.

> 예전에 쓰이던 **"우클릭 → 열기"** 우회는 macOS 15(Sequoia)부터 막혔습니다.
> 위의 시스템 설정 경로를 쓰세요.

## 기능

### 비율 변환

- 비율: 1:1 · 3:4 · 4:3 · 16:9 · 9:16
- **잘리지 않게** — 여백을 채워 비율을 맞춥니다 (배경색 흰색/검정)
- **꽉 차게** — 중앙을 잘라 비율을 맞춥니다
- 출력 형식: JPG · PNG · WEBP (품질 조절)
- 출력 해상도를 직접 지정할 수 있습니다. 지정하지 않으면 각 이미지가 자기 해상도를 지킵니다

### ICO 변환

- 256×256 아이콘으로 만듭니다
- 마스크 모양: 원형 · 사각형 · 라운드(모서리 반경 조절)
- 마스크 크기와 이미지 크기를 슬라이더로 조절

### 그 밖에

- 창에 이미지를 끌어다 놓거나 폴더째로 넣을 수 있습니다 (JPG · PNG · WEBP)
- 변환 전후를 나란히 미리 봅니다. 예상 파일 크기도 표시됩니다
- 파일명 공식: `{name}` `{ratio}` `{n}` — 시작 번호와 자릿수를 정할 수 있습니다
- 설정은 앱을 껐다 켜도 유지됩니다

## 업데이트

앱을 켤 때 새 버전을 확인합니다.
Windows는 자동으로 받아 재시작할 때 설치하고, macOS는 이 페이지로 안내합니다.
